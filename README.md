CodeAlpha Task 2 : Image Gallery 
🖼️ Interactive Image Gallery | CodeAlpha Project
Welcome to my Image Gallery project built with HTML, CSS, and JavaScript as part of the CodeAlpha internship! This sleek, responsive gallery lets you explore a collection of beautiful images with a smooth and interactive user experience. 🌟

🚀 Features
🔍 Hover Zoom: Hover over any image to see a subtle zoom-in effect.

💡 Lightbox View: Click an image to open it in a fullscreen overlay with dark background (JavaScript-powered).

📱 Fully Responsive: Looks great on mobile, tablet, and desktop.

🎨 Custom CSS Styling: Clean layout with smooth transitions and modern design.

🛠️ Built With
HTML – Semantic structure

CSS – Flexbox/Grid for layout, transitions, and responsiveness

JavaScript – Dynamic image interactions and lightbox functionality
